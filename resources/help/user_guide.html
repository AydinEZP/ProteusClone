ProteusClone User Guide

ProteusClone is an educational Proteus-like circuit design and simulation program built for an Object-Oriented Programming project. This guide explains the main workflow, controls, circuit editing tools, simulation behavior, instruments, file handling, and troubleshooting tips.

1. Quick Start

  1. Start the application.
  2. Choose New Project from the start dialog or from File > New.
  3. Select a canvas size preset or enter a custom width and height.
  4. Pick components from the Library dock on the left.
  5. Click on the canvas to place the selected component.
  6. Use Wire Mode or press W to connect pins.
  7. Press F5 or use Simulation > Run to start simulation.

4. Appearance and Theme

  • Open View > Theme to choose System (Automatic), Light, or Dark.
  • System (Automatic) follows the operating-system color scheme. On supported Qt versions, the application updates when the OS theme changes.
  • Your selected theme mode is saved and restored the next time the application starts.

5. Canvas Navigation

  • Zoom: use the mouse wheel.
  • Pan: drag with the supported pan mouse button, depending on your build configuration.
  • Coordinates: the status bar shows live world coordinates.
  • Snap: components and routing points snap to the design grid to keep the schematic aligned.
The grid is a visual alignment aid. Circuit connectivity is determined by pins, wires, and junctions, not by merely drawing objects near each other.

6. Component Library

The library is organized into categories such as sources, passive parts, interactive components, digital parts, advanced components, and measurement tools.

  • Use the search field to filter by component name or category.
  • Select a component to preview its symbol.
  • Click on the canvas to place a new instance.
  • Placed components become part of the current project and can be selected, edited, moved, wired, saved, and simulated.

9. Wiring

  • Press W or use the Wire toolbar button to enter wire mode.
  • Move the mouse near a pin; the pin should highlight when it can be used.
  • Click a source pin to start routing.
  • Click empty grid points to add 90-degree bend points.
  • Click a destination pin to finish the wire.

90-degree routing

Wires should be composed of horizontal and vertical line segments. Diagonal wires are not used for schematic routing.

Crossings and junctions

  • If two wires simply cross, they are not electrically connected.
  • Create a dot junction at a crossing point when you want an electrical connection.
  • Junctions are represented visually by small filled dots and logically by shared net nodes.

11. Logic Simulation

Digital logic uses ideal voltage levels:

  • LOW: 0V
  • HIGH: 5V
  • Undefined: floating input, invalid voltage range, conflicting drivers, or undetermined signal.

Undefined inputs should produce a warning such as Floating input detected. and propagate undefined behavior where applicable.

12. Analog / Hybrid Simulation

The simulator uses a simplified hybrid approach:

  1. Digital components are evaluated.
  2. Digital outputs are converted to ideal 0V/5V voltage sources where needed.
  3. The analog network is advanced using a simplified nodal/matrix model.
  4. Measurement tools and visual components are updated from the solved node voltages.
This is an educational simulation model. It is not a full SPICE replacement, but it is designed to support common OOP project demonstrations such as DC sources, resistors, capacitors, inductors, logic gates, ADC/DAC, and measurement tools.

13. Interactive Components

ComponentInteraction
SwitchToggle between open and closed. Electrically, a closed switch merges A and B into one ideal net; an open switch leaves the two sides completely disconnected. No artificial high/low resistance is used.
PushButtonA one-pin momentary digital source. Hold the left mouse button on the component to drive OUT HIGH (5V); release it to drive OUT LOW (0V). Use Ctrl+drag to reposition the button.

KeypadUsed as a matrix input device for MCU-style tests.

14. Measurement Tools

Voltage Probe

Use a probe to inspect the instantaneous voltage of a pin, wire, or node during Run or Pause.

Voltmeter

A two-terminal voltmeter displays the voltage difference between its terminals. If no valid ground/reference exists, it may show ERR.

Ammeter

An ammeter estimates current through the measured branch. For ideal digital inputs, current is expected to be approximately zero.

Oscilloscope

  • Supports at least two independent channels.
  • Each channel has its own color, Volt/Div, and vertical offset.
  • Time/Div controls the shared horizontal time base.
  • Waveforms are drawn from left to right as simulation time advances.
  • In Pause, the displayed trace is held.
  • In Stop, the oscilloscope buffer is cleared/reset.

15. ADC and DAC

Pin labels: multi-I/O symbols show their pin names directly on the schematic. ADC uses VIN, VREF+, VREF- and D0..D(N-1). DAC uses D0..D(N-1), VREF+, VREF- and VOUT. MCU symbols expose four 8-bit GPIO ports P0.0..P3.7 plus VCC and GND. Seven-segment displays visibly label A, B, C, D, E, F, G, DP and COM.

ADC

  • Inputs: analog input, Vref+, Vref-.
  • Outputs: N independent digital output bits.
  • Out-of-range analog input saturates to 0 or 2^N - 1.
  • Conversion delay keeps the last valid output until the delay has elapsed; no external CLK pin is required.

DAC

  • Inputs: N digital input bits, Vref+, Vref-.
  • Output: analog voltage mapped linearly from the digital code.
  • Conversion delay keeps the last valid analog output until the delay has elapsed.

16. Microcontroller, Firmware, LCD, Keypad, and External Memory

  • The firmware loader reads validated Intel HEX-style files.
  • The microcontroller model includes program counter, accumulator, internal RAM/Flash state, and a simplified instruction decoder.
  • The MCU exposes four independent 8-bit ports: P0, P1, P2, and P3. Every GPIO bit can be configured as input (high impedance) or output.
  • SETB and CLR make the addressed bit an output automatically. Full-port input/output and direction instructions are also supported.
  • The LCD 16x2 component displays text and receives simplified RS/RW/E/D0..D7 bus commands.
  • The 4x4 keypad is clickable directly on the schematic. Hold the mouse on a key to close that row/column contact and release the mouse to open it. Use Ctrl+drag to move the keypad.
  • The external memory supports true bus reads and writes. RD and WR are active-low; during RD the memory drives D0..D7, and during WR it samples D0..D7. RD and WR must not be active at the same time.

Educational MCU bytecode additions

OpcodeOperandsOperation
0x42portMOV Pn,A — write ACC to a whole port and make all 8 bits outputs.
0x43portMOV A,Pn — read the current pin levels of a port into ACC.
0x44port, maskDIR Pn,#mask — bit 1 means output; bit 0 means input/high-impedance.
0x45port, immMOV Pn,#imm — write an immediate byte and make all 8 bits outputs.

18. Recommended Test Circuits

  1. Voltage divider: DC source + two resistors + ground + voltmeter.
  2. RC transient: DC source + switch + resistor + capacitor + oscilloscope.
  3. Logic gate: Clock or sources driving AND/OR/NOT gates and LED outputs.
  4. D Flip-Flop: D source + clock source + Q output probe or oscilloscope.
  5. ADC/DAC loop: analog voltage to ADC, digital bus to DAC, measure DAC output.
  6. Junction/crossing: verify that crossed wires are not connected unless a junction dot exists.

19. Blocking DRC and Safe Simulation Stop

Before Run, and again before each analog matrix solve, the simulator validates blocking electrical faults:

  • Conflicting drivers / short circuit: if one net is driven to incompatible ideal voltage values, Run is blocked or stopped before MNA is evaluated.
  • Floating required input: wiring inputs together is not enough; an input net must have a real path to a valid source or reference.
  • Solver failure: if the circuit matrix still cannot be solved safely, simulation stops and the Log / DRC panel reports the failure.
  • Successful validation: the Log / DRC panel also reports when blocking checks pass and simulation starts.

An open Switch is a true disconnection. Its isolated side remains FLOATING; it is never converted into a fake 0V by a large resistance or numerical regularization.

20. Troubleshooting

ProblemLikely cause and fix
The EXE does not open outside Qt CreatorDeploy Qt runtime files. Use deploy_windows_mingw.bat after a successful build, or run through Qt Creator.
No suitable Qt kit foundInstall Qt 6 MinGW 64-bit, CMake, Ninja, and MinGW through Qt Maintenance Tool. Then reopen the project.
Component value becomes zeroCheck unit formatting. Use supported forms such as 100 nF, 1k, or 5V.
Wire does not connectMake sure the wire starts and ends on highlighted pins, not just near component drawings.
Crossed wires act disconnectedThis is correct unless a junction dot is placed at the crossing.
Oscilloscope line is flatVerify that the channel pins are connected to valid nets and that simulation is running.
Unexpected logic warningCheck for floating inputs, no ground reference, or multiple conflicting drivers.
Run stops immediatelyBlocking DRC is intentional: a required input with no real electrical source/reference, or a net driven to conflicting ideal values, prevents or stops Run before the analog matrix is solved. Correct the wiring and run again.
Analog solve failedThe simulator stops safely instead of continuing with invalid matrix results. Check ideal-source conflicts, direct source shorts, and missing electrical references.
Seven-segment stays darkThis is a common-cathode model. Wire COM to the low/reference side and drive A..G above COM. DP is optional.

22. Notes for Students and Demonstration

  • Use simple test circuits first, then move to mixed analog/digital examples.
  • Always place at least one GND before expecting analog voltage tools to behave correctly.
  • Use the DRC log before running complex circuits.
  • For presentation, prepare at least one circuit each for analog, digital, oscilloscope, ADC/DAC, and wire/junction behavior.
