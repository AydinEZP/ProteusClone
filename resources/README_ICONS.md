# Project Icons

These icons were generated specifically for the ProteusClone Qt project.
They are embedded through `resources/resources.qrc` under the `/icons` prefix.

Typical usage:

```cpp
QIcon(":/icons/app.png")
QIcon(":/icons/run.png")
QIcon(":/icons/wire.png")
```

The Windows executable icon is provided as `resources/icons/app.ico` and referenced from `resources/windows_icon.rc`.
