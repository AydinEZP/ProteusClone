# Final package

This package contains the maximum feature-aligned Qt/C++ implementation prepared in this environment.

Build requirement: Qt 6 Widgets + CMake + C++17 compiler.

Implemented feature groups include start menu, canvas/grid/zoom/pan/snap, component library search/preview/active list, component editing/selection/multiselect/drag/rotate/mirror/delete, wires, junctions, JSON persistence, recent projects, undo/redo, export image, simulation controls, DRC/logs, basic/digital/advanced components, probes/meters/oscilloscope, and simplified HEX loader.

Important: this environment does not have Qt installed, so the project could not be compiled here against Qt.
