# User Guide

## Creating a Project

Run the application, choose **New Project**, then select or enter the canvas size.

## Placing Components

Use the component library to select a device, then click on the canvas to place it. Components snap to the grid.

## Editing Components

- Click to select a component.
- Drag to move it.
- Use the properties panel or double-click to edit values.
- Use rotate/mirror actions from the UI where available.
- Press Delete to remove selected items.

## Wiring

Select the wire tool and connect component pins. Wires are routed with 90-degree segments. Junction dots indicate electrical connection at crossings.

## Running Simulation

Use **Run**, **Pause**, **Stop** and **Step**. Critical DRC errors block simulation.

## Measurements

Use voltage probes, voltmeters, ammeters and the oscilloscope to inspect circuit behavior.

## Oscilloscope

Click an Oscilloscope component to open the oscilloscope panel. The panel can be closed and reopened later by clicking the component again.

## Theme

Use **View > Theme** to select System, Light or Dark mode.

## Save/Load

Use project save/load actions to store and restore `.pcj` circuit files.
